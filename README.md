# WINNER — управленческий учёт "SAVER PAINTS" MCHJ

Веб-приложение для учёта сырья и готовой продукции компании **"SAVER PAINTS" MCHJ** (краски, лаки, типографская краска, мастики). Сделано по ТЗ «Программа для управленческого учёта компании WINNER».

Работает на телефоне, планшете и ноутбуке. Три языка интерфейса с плавным переключением: **RU · ЎЗ (узбекский, кириллица) · UZ (узбекский, латиница)**. Светлая и тёмная тема.

## Разделы (по ТЗ, п. 3)

| Группа | Разделы |
|---|---|
| Обзор | Сводка (8 показателей п. 4.5, графики), Отчёты (п. 4.8 — печать и выгрузка в Excel) |
| Продажи | Продажи (оплаты, возвраты, долги по отгрузке, история; заказ по телефону; накладная и счёт-фактура), Контрагенты |
| Финансы | Расход, Касса (5 остатков), Банк (подтверждение бухгалтером, правка в строке с историей) |
| Производство | Производство (выпуск, остатки сырья с потребностью, калькуляция на 1 шт, номенклатура с порогом), Склад (приход/расход/остаток, отгрузки по стадиям, движение, перемещения), Приход (закупка, поставщики), Каталог (карточки с фото) |
| Сотрудники | Зарплата (начисления, сотрудники, выплаты и отчёты RU/UZ, история изменений) |
| Управление | Сотрудники (пользователи, роли, новый пароль, «Защищено»), Администрирование (реквизиты, валюта и курс, нумерация документов, порог, перенос из Excel, резервная копия) |

Плюс **личный кабинет**: смена своего пароля, язык, тема, моя активность.

## Роли

Директор (всё), Бухгалтер, Менеджер по продажам, Продавец магазина, Кладовщик, Технолог производства. Каждый видит только разделы своей роли. Логины и пароли демо-пользователей — в `ACCESS.txt` (файл не попадает в git), в коде хранятся только SHA-256 хэши.

## Как устроено

- Статический сайт без сборки: `index.html` — вход, `app.html` — кабинет (hash-роутер `#/раздел?tab=…`).
- Данные — демо в `localStorage` браузера (`wn.db.v1`), генерируются при первом входе (`assets/js/data.js`) с датами от сегодняшнего дня. Сброс: Администрирование → «Сбросить демо-данные».
- `assets/js/core.js` — база, права, расчёты (остатки из журнала движений, касса, банк, долги, потребность в сырье, ведомость).
- `assets/js/ui.js` — компоненты: модалки/шторки, тосты, таблицы (на телефоне превращаются в карточки), свой выпадающий список с поиском, графики SVG, печать, CSV.
- `assets/js/i18n.js` + `i18n-dict.js` — переводы. Ключ — русская строка, значение — узбекская латиница; кириллица строится транслитерацией.
- Шрифты Geologica и Golos Text лежат локально, включая подмножество cyrillic-ext для букв Қ Ғ Ҳ Ў.

## Запуск локально

```bash
python -m http.server 8840
```

Открыть http://localhost:8840 (вход нужен по http(s) — пароли проверяются через Web Crypto).

## Добавить строку перевода

Пишите в коде `t('Русский текст')`, затем добавьте пару в `assets/js/i18n-dict.js`:

```js
"Русский текст": "O'zbekcha matn",
```

Апострофы пишутся обычные (`o'`, `g'`, `ma'lumot`) — программа сама заменит их на `ʻ`/`ʼ` и построит кириллицу.
